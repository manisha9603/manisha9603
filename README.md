### Projects

**IntellMeet** — real-time video conferencing platform
A full-stack app with live video/audio (WebRTC), in-call chat (Socket.IO), and AI-generated meeting transcripts using Groq's Whisper and LLaMA models. Originally built on OpenAI's API; migrated to Groq's free tier to keep the project sustainable without losing transcription quality. Backend on Render, frontend on Vercel, with a centralized API config layer instead of hardcoded environment references — one line to change per environment, not a find-and-replace across the codebase.

`React` · `TypeScript` · `Node.js` · `Express` · `Socket.IO` · `MongoDB` · `WebRTC` · `Groq API`
[→ github.com/manisha9603/IntellMeet](https://github.com/manisha9603/IntellMeet)

**EcoTrack Pro** — gamified campus sustainability platform
Tracks and rewards eco-friendly student behavior through a challenge and points system. Took this from local prototype to a working deployment — resolving CORS misconfiguration between the separately-hosted frontend and backend, fixing MongoDB Atlas network access rules, and untangling a double-nested repository structure that was breaking the Vercel/Render build pipeline.

`React` · `Vite` · `Node.js` · `Express` · `MongoDB`
[→ github.com/manisha9603](https://github.com/manisha9603)
